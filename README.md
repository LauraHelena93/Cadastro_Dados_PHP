Um projeto simples e funcional de **Cadastro de Dados**, desenvolvido durante os primeiros estudos de integração entre **HTML5**, **CSS3** e **PHP** para processamento backend de formulários web.

---

## 📌 Sobre o Projeto

O objetivo deste projeto é capturar dados preenchidos por um usuário através de um formulário interativo no front-end (`cadastro.html`) e enviá-los via método **POST** para processamento dinâmico e exibição personalizada no back-end (`processaCadastro.php`).


### 🎯 Campos do Formulário
- **Nome completo** (`text`)
- **Idade** (`number`)
- **Profissão** (`text`)
- **Salário pretendido** (`number`)
- **Experiências anteriores** (`textarea`)

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação e criação das tags do formulário.
- **CSS3**: Estilização visual (box model, card centralizado, bordas arredondadas e paleta suave).
- **PHP**: Captura e renderização dinâmica das variáveis recebidas no servidor.
- **VS Code**: Editor de código principal.
- **XAMPP / Apache**: Servidor local para execução do PHP.
